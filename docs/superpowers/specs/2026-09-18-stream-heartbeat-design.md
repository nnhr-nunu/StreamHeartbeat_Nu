# StreamHeartbeat(ぬ) 初回公開 設計

日付: 2026-09-18  
状態: 合意済み（grill 反映）

配信中に心臓の脈動を OBS へ出す Windows アプリ。医療機器ではない。

## 目的

VTube Studio と OBS を使う配信者が、アバターの上に心拍同期の心臓を乗せる。操作は配信前に済ませ、配信中は触らなくても動く。スライダーはいつでも配信用へ即反映する。

## 非目標（初回）

- Mac / ブラウザソース本線 / VTS プラグイン本線
- Live2D 本線、任意 3D ファイル読み込み
- 配信ミックス全体からの心音分離 AI
- 配信中の自動学習
- BLE 秒以下中継、Google Health の再実装
- 心音のクラウド送信
- 操作画面を閉じたあとの出力だけ残留
- 「出力だけ隠す」ボタン

## 窓

| 窓 | 役割 |
| -- | ---- |
| 操作画面 `StreamHeartbeat(ぬ)` | 設定・キャリブ・検出状態・OshiLog 補助 BPM・「医療機器ではない」 |
| 配信用 `StreamHeartbeat(ぬ) - 配信出力` | OBS ウィンドウ取り込み。中身はクロマキー緑＋視聴者向け画素だけ |

配信中は両方開いたまま。操作画面を閉じる＝プロセス終了＝配信用も消える。

配信用はタイトル付きの普通の窓。緑はキャンバス全面。枠が写るなら OBS でクロップ。緑の色は固定 `#00FF00`。心臓・文字はこの緑を使わない。

配信用に出してよいもの: 心臓、同期文字、設定オンの BPM 数字、条件時の「不整脈！」類。検出ロスト・パス・例外は操作画面のみ。

## 入力と時計

ドクンの時計と画面の BPM 数字は心音。専用マイクを共有モードで開く（OBS と同じデバイスでも独占しない）。

配信前キャリブ: 心音を流す＋少し喋るセッションをプロファイルに足せる。失敗セッションは捨てられる。配信中は型を更新しない。

拍が外れたら最後の BPM で打ち続ける。操作画面は「検出できていません」。心音が戻ったらすぐ本物の拍。配信側に未検出とは出さない。

## OshiLog

Google Health はコピーしない。音は送らない。公開心拍 ID をプロファイルに保存し、取れた最新 BPM は操作画面の補助と高めゾーン演出の参考。動きと BPM 数字は心音。ズレが大きいときは操作画面にだけ警告。

未認証の公開 API はデバイス解決までで BPM 本体は別経路になり得る。その場合はプロファイルの任意 JSON URL（`{"bpm": 数}`）で補助 BPM を読む。どちらも無いときは補助なしで心音だけで動く。

## 見た目

描画エンジンは一つ。スタイルは差し替え。

| スタイル | 初回 |
| -------- | ---- |
| リアル | 立体感のある内蔵心臓（3D メッシュ、難しければ同等の陰影付き立体表現） |
| かわいい | 2D |
| 機械 | 2D |
| 心電図 | 横スクロール波形 |

Live2D と任意 glTF は次（差し込み口は空けてよい）。

大きさ・透明度はプロファイル。スライダー変更は配信用へ即反映。

同期文字（既定「ドクン」）と「不整脈！」は同じふわっと表示。配信用枠の内側（余白 15%）で毎回ランダム。同時表示は最大 3。フェードイン約 0.25s、保持 0.2s、フェードアウト 0.35s。不整脈はエンタメ。診断しない。操作画面に「これは医療機器ではありません。診断・治療には使えません。」

拍間隔が直近中央値から 25% 超ずれて 2 回続いたら不整脈演出。クールダウン 8 秒。

## プロファイル

名前つき JSON。マイク、キャリブ、スタイル、文字、透明度、大きさ、BPM 表示、OshiLog ID / 補助 URL を含む。

保存場所:

1. exe と同じ階層に `data` フォルダがあればそこ（ポータブル）
2. なければ `%LOCALAPPDATA%\StreamHeartbeat_Nu\`

配布 zip に `data` も AppData の中身も入れない。起動は前回プロファイル。キャリブが無いときは未検出扱い（最後の BPM が無ければ 70 で打ち始め、操作画面は未検出）。

## 品質

- ロジックはウィンドウクラスに直書きしない（入力 / 時計 / 描画状態 / 設定）
- 型ヒント、`from __future__ import annotations`
- テストは時計・プロファイル・検出・不整脈を単体。Qt 窓はタイトル契約程度
- commit 前 `pytest`
