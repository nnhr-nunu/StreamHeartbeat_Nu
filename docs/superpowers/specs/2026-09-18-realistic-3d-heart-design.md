# 立体心臓（OpenGL）設計

日付: 2026-09-18  
状態: 実装済み（断面と血液の飛びは未着手、`task.md` R-3）  
親仕様: [2026-09-18-stream-heartbeat-design.md](./2026-09-18-stream-heartbeat-design.md)

配信の「リアル」「機械」「レントゲン」「MRI」を、同じ立体心臓に質感を差し替えて描く。医療機器ではない。診断しない。

## 目的

心音の時計に合わせて、立体の心臓が縮み・捩れ・太い血管が膨らむ。質感は表で管理し、あとから断面図などを同じ一覧に足せる。

## 非目標（この変更）

- Three.js / ブラウザ埋め込み / Chromium
- ユーザーが任意の 3D ファイルを読み込む
- 手術器具・開胸の周囲・縫合糸
- 断面図そのもの
- 配信用キャンバスへのデバッグ文字
- かわいい / 心電図 / 心エコーの 3D 化（これらは 2D）

## 画面

配信用の窓はこれまで通り OBS が取り込む。背景は固定緑 `#00FF00`。心臓の画素はこの緑を使わない。

| 場所 | 操作 |
| ---- | ---- |
| 配信用キャンバス | 立体スタイルのとき左ドラッグで心臓を回す。ダブルクリックで初期の向き。ホイールでは大きさを変えない |
| 操作画面 | スタイルがリアルのときだけ「質感」一覧。立体スタイルのとき「角度を固定」「角度をリセット」。固定は起動のたびにオフ。角度の数値はプロファイルに保存 |

初期の向きは解剖図寄り。縦回転は ±89° で止め、横回転は一周できる。感度は 0.35° / ピクセル。

## 質感

形はメッシュ 1 体。質感だけ変える。

| スタイル | キー | 質感 |
| -------- | ---- | ---- |
| リアル | `surgical`（既定） | 黄色い脂肪、冠動脈、細い血管の網、湿った強い光沢 |
| リアル | `anatomy` | 脂肪を抑え、溝と血管が読みやすい。光沢は弱め |
| 機械 | `mech` | 段ずらしの外板、面取り、リベット、拍で光る継ぎ目。管はクロームに締め輪 |
| レントゲン | `xray` | 加算合成の濃度。厚いところが白い。2D の胸郭・肋骨と重ねる |
| MRI | `mri` | 加算合成の赤い濃度と動く粒子。2D の胸壁断面と重ねる |

リアルのキーはプロファイル `realistic_look`。不明なキーは `surgical` に落とす。

## 拍動

時計は今の `CardiacCycle`（心音が正本）。全体を同じ倍率で潰さない。頂点シェーダーが部位ごとに動かす。

| 部位 | 収縮（squeeze） | 送り出し（eject） | 充満（fill） |
| ---- | --------------- | ----------------- | ------------ |
| 左室 | 中へ縮む（心尖側ほど強い）。房室弁の面が心尖へ下がる | — | ゆるむ |
| 右室 | 左室の約 0.6 倍 | — | ゆるむ |
| 心房 | 少し膨らむ | — | 戻る |
| 心尖 | ほぼ動かず、長軸まわりに最大 18° 捩れる。少し前へ突く | — | 戻る |
| 太い動脈 | — | 径が最大 +12% | 戻る |
| 上大静脈 | — | — | わずかに太る |

## 描画の箱

- 配信用キャンバスは `QOpenGLWidget`。追加の 3D ライブラリは入れない。
- 1 フレームの順: 緑 → 2D 背景（レントゲン・MRI のパネル） → 立体心臓 → 2D 前景（肋骨・粒子） → 同期文字・BPM。
- OpenGL を初期化できない、またはシェーダーが通らない: 2D の代替で描く。操作画面にだけ短い失敗表示。配信用には出さない。
- 大きさ・透明度スライダーは立体にも即反映。

## メッシュ

起動時に数式から生成する（約 0.2 秒、約 8 万頂点）。外部モデルは使わない。

- 4 つの腔は向きの違う楕円体の滑らかな合成。腔の境目に溝を刻み、溝の周りに脂肪量を持たせる。
- 大動脈・肺動脈幹・上大静脈は曲線に沿った管。端は開口し内腔を暗く塗る。
- 頂点属性: 位置・法線・部位（左室 0 / 右室 1 / 左房 2 / 右房 3 / 動脈 4 / 静脈 5 / 内腔 6）・脂肪量・長軸位置・UV。
- 三角形の表は法線側。テストで検証する。

## プロファイル

| フィールド | 既定 | 意味 |
| ---------- | ---- | ---- |
| `realistic_look` | `"surgical"` | 質感キー |
| `heart_yaw_deg` | `-18` | 横回転 |
| `heart_pitch_deg` | `12` | 縦回転 |

角度の固定は保存しない。

## テスト

GPU が無ければオフスクリーン描画のテストはスキップ。

- メッシュ: 部位が揃う、法線が単位長、三角形が表向き
- 質感表: リアル 2 件、スタイル 3 件、加算合成の指定
- 回転のクランプ・巡回
- オフスクリーン描画: 中央は緑以外、隅は緑

## 回帰（人が見る場所）

- 配信用: 緑の上の心臓・文字・BPM だけ。ドラッグで回る。レントゲン・MRI はパネルの外が緑。
- 操作画面: 質感一覧、角度固定、立体失敗時の文言。「医療機器ではない」は残す。
