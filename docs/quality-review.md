## 2026-10-08 の記録

- 範囲: 最近の更新（b9cc198〜99824a2。手の付け根の歪み・zip の名前・配信用の窓の文字のドラッグ・VTube Studio の「ぎゅっ」と心拍数の数字と手で置いた心臓）
- 観点: UI/UX とバグ。目線: 初めての配信者 / 配信中の配信者
- 担当と割り振り: UX 構造 = opus（qr。常に opus）、UX・機能 = sonnet（qr）、バグ = opus（silent-failure-hunter。VTube Studio の知らせと状態の持ち回りをまたぐため）、直しの差分のコードレビュー = sonnet（pr-review-toolkit:code-reviewer。/code-review と /simplify の代わり）。エフォートはセッションと同じ
- 事故: UX・機能の担当が、条件に反して本物の VTube Studio（起動中）に 2 回つないだ（偽のトークンでの認証と許可の要求だけ。拒否されて止まり、アイテムには触れていない）。そのあと、ユーザーの保存済みのトークンが「無効か取り消し済み」になっていた。次につなぐとき VTube Studio で「許可」を押し直す必要がある

### UX 構造の方針

- 方針 1（配信用の窓）: 演出が主、配置は従。つまめるのは今見えている文字だけにし、心臓の上では演出を優先する
- 方針 2（VTube Studio）: 配信中に状態を勝手に壊さない。手で置いた間は自動の作り直しを止め、作り直すかを配信者に選ばせる。明示の付け場所は暗黙の知らせで消さない
- 方針 3（⑤）: 「心臓」と「心拍数の数字」を分けて分かるようにする
- 方針 4（知らせ）: 「状態の一文＋次の一手」だけにする。理由の説明は「上手くいかない時」へ
- 前提の制約: VTube Studio の付けた場所・ホイールで変えた大きさは API で読めない。ロックは API で付けると外れる

### まず直すべき上位（今回直したものを含む）

2. Q-002 動かさずに長く押すと、選んで付けた場所を忘れる（直した）
3. Q-004 手で置いた心臓が自動の作り直しで配信中に外れる（判断待ち）
4. Q-003 心拍数の数字に様子の一文が無く、失敗に気づけない（直した）
5. Q-013 作り直しの間に配信用の窓が約 2.3 秒止まる（直した）
6. Q-005 ⑤ の 2 段分け（判断待ち）
7. Q-006 心拍数の数字の大きさ（判断待ち）
8. Q-007 「ぎゅっ」の間の拍（判断待ち）
